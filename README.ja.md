# Pumpkin 2048 — ハロウィンの数字合成パズルとランタンの試練

🎃 小さなかぼちゃを滑らせて、大きなかぼちゃへ。**Pumpkin 2048** は、おなじみの 4×4 数字パズルを月夜の庭に移したゲームです。Classic Garden でスコアを伸ばす楽しみと、数字の「最後の位置」まで考える3つの Lantern Trials を遊べます。

**[ブラウザーで遊ぶ](https://halloween-2048.crazy3d.org/)** · [全12作のハロウィンゲームを見る](https://github.com/AshinTop/halloween-games) · [⭐ GitHub で Star を付ける](https://github.com/AshinTop/halloween-2048)

## このゲームの楽しみ方

- **Classic Garden**：基本の 2048 ルールで自己ベストを目指し、2048 を作ったあとも続けられます。
- **3つの Lantern Trials**：固定盤面、光る目標マス、手数制限を組み合わせた問題。途中でランダムなタイルは増えません。
- **各試練で1回の Moon Swap**：数字の違う、埋まっている2マスを1手で交換。3問とも、この魔法を使わない解法も確認済みです。
- オリジナルの SVG イラストと、128・512・1024・2048 の庭の目印。合成効果音は任意で、動きを減らす設定にも対応します。
- Undo は盤面、スコア、手数、魔法の使用状態を戻します。スワイプ、画面ボタン、キーボードで操作できます。

## 基本ルール

**Classic Garden** では、すべてのタイルを選んだ方向へ滑らせます。同じ数字が接すると合成され、8 と 8 は 16 になります。合成直後のタイルが、その1手の中でもう一度合成されることはありません。盤面が動いた手のあとには 2 または 4 が追加されます。何も変わらない方向を押しても新しいタイルは増えません。2048 を作れば目標達成で、その先も続行できます。盤面が満杯でも動ける手があれば続き、合法な移動がなくなると終了します。

**Lantern Trials** では、最初に目標欄を確認します。指定された数字を、手数以内に光るマスへ置いてください。新しいタイルが増えないので、同じ問題をじっくり考え直せます。Moon Swap は魔法を選んでから、異なる数字のタイルを2つ選択します。空きマスや同じ数字は交換できません。交換も1手に数えられ、Undo で戻すと魔法も未使用に戻ります。

## 操作方法

| 操作 | 入力 |
| --- | --- |
| タイルを滑らせる | 矢印キー、スワイプ、画面の方向ボタン |
| 1手戻す | **U** または Undo |
| Moon Swap | 魔法を選び、数字の違うタイルを2つ選択 |
| 魔法の選択を取り消す | **Esc** |
| やり直し・説明・音 | 画面のボタン。キー操作にはゲーム内のフォーカスが必要 |

## ちょっとしたコツ

目の前の合成だけでなく、次に同じ数字を近づける通り道も残しましょう。試練では目標マスを先に見ておくのが大切です。大きな数字を作っても、別の位置にあると達成にはなりません。Moon Swap は配置を整える助けになりますが、手数は消費します。迷ったら Undo を使い、2通りの進め方を比べてみてください。

## 記録とチャレンジの共有

保存が許可されていれば、Classic の途中盤面、設定、ローカル記録を同じブラウザーに保存します。Undo の履歴はページを開いている間だけ残り、最大 **50手**です。すでに獲得した最高スコアは取り消しません。[試練1](https://halloween-2048.crazy3d.org/?trial=1)から始められ、パラメーターを 2・3 に変えると別の試練を開けます。共有内容は実際の結果とリンクで、未クリアの挑戦を勝利として表示しません。共有機能やクリップボードが使えない場合は、コピー用の文字を表示します。

## よくある質問

### Classic Garden で Moon Swap は使えますか？

使えません。Lantern Trials 専用で、各問題に1回だけ。交換にも手数が必要です。

### すべての試練に解法がありますか？

はい。3つの固定問題は、魔法を使わない完全な手順をテストしています。ただし、どんな順序で動かしても解けるという意味ではありません。

### 別の端末にセーブを引き継げますか？

アカウント同期はありません。記録はブラウザーと配信元ごとに保存されます。保存が使えなくてもプレイはできます。

## ローカルで実行・サイトに埋め込む

リポジトリのルートで HTTP サーバーを起動します。

```sh
python3 -m http.server 4173
```

**http://localhost:4173/** を開いてください。ビルドや依存パッケージは不要です。`file://` では JavaScript モジュールを読み込めない場合があります。

Node で付属のチェックを実行します。

```sh
npm test
```

テストでは、1手に1度の合成、盤面が変わらない入力、決定的な生成、行き詰まり、魔法の消費、全試練の解法、保存内容とリンクの検証を確認します。実機スマートフォンの性能測定ではありません。

```html
<iframe src="https://halloween-2048.crazy3d.org/?embed=1"
  title="Pumpkin 2048"
  style="display:block;width:100%;height:654px;border:0"
  allow="fullscreen" allowfullscreen></iframe>
```

デスクトップの基準は **1160×654 CSS ピクセル**です。390×650、390×794、844×340 のブラウザー枠も確認しています。盤面は iframe 自体の領域に合わせ、長い説明や結果はパネル内でスクロールできます。

寸法、保存、フォーカス、権限は[埋め込みガイド](EMBEDDING.md)へ。親サイトのツールバーを除いた高さを iframe に割り当ててください。
